# Coding Standards

Read before public API, compatibility, configuration, dependency, generated-file, or documentation changes.

## Current Python Package

- Use Python 3.11-compatible syntax and uv. Configuration lives in [pyproject.toml](../../pyproject.toml), [setup.cfg](../../setup.cfg), and [.pre-commit-config.yaml](../../.pre-commit-config.yaml). Use configured Black/isort/flake8 rather than restyling unrelated code.
- Follow existing typed functions and pytest fixtures. Type new public interfaces; migrate direct callers and tests with signature changes.
- [szuru_toolkit.py](../../src/szurubooru_toolkit/scripts/szuru_toolkit.py) owns Click registration and option collection. Preserve explicit-option precedence over config values; test absent options as well as overrides.
- [config.py](../../src/szurubooru_toolkit/config.py) owns defaults, file discovery, and validation. Do not mutate module defaults or silently change search order.
- Scripts orchestrate existing client/utility behavior. Inspect actual imports before moving code: globals and deferred imports make startup order significant.
- [concurrency.py](../../src/szurubooru_toolkit/concurrency.py) owns the shared thread-pool helper. Import it directly in new code; [utils.py](../../src/szurubooru_toolkit/utils.py) retains the old `run_concurrently` export for compatibility. Config/client globals and other utility responsibilities have not been migrated.
- Preserve partial-failure and exit semantics deliberately. A log message or zero exit code alone may not mean every item succeeded.
- Reuse structured parsers and maintained libraries. Avoid speculative abstractions, broad exception swallowing, and unrelated cleanup.
- [uv.lock](../../uv.lock) is generated by uv; change dependency declarations deliberately and regenerate with `uv lock`, reviewing the resulting scope. Do not hand-edit the lockfile.

## Web Boundaries

Read [the plan](../plans/web-ui.md) and [backlog](../decisions/backlog.md) when implementing the web application. These are target constraints, not available interfaces.

Keep reusable CLI/core logic independent of the optional web package. The current read-only scaffold does not initialize toolkit config or clients. Vue consumes a versioned API, not toolkit credentials or direct filesystem access. Future jobs must use isolated CLI child processes; do not retrofit request-local assumptions onto process-global modules.

Follow [frontend guidance](../../frontend/AGENTS.md), [API guidance](../../src/szurubooru_toolkit/web/AGENTS.md), and [the setup guide](../WEB_UI.md) for npm scripts and offline OpenAPI generation. Regenerate the typed client and run its drift check with schema changes. Auth, migrations, profiles, and job execution remain unimplemented; do not describe them as available authorities.

## Editing Discipline

Find the controlling behavior and cheapest discriminating test before editing. Run that test immediately after the first substantive edit. Keep direct tests and implementation together, preserve user changes, and stop before widening scope to unrelated failures.

Describe current contracts and surprising invariants in documentation; keep unimplemented architecture in planning documents. Avoid duplicating the helper source kit as active policy.
