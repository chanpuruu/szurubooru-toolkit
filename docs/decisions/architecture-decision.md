# Architecture Decision Outline

Read [ADR-0000](0000-record-architecture-decisions.md) before creating a numbered record. This file is an outline, not an accepted runtime decision. Write concrete content rather than copying unresolved markers.

## Metadata

Add YAML frontmatter with status, ISO calendar date, accountable deciders, discovery tags, and a specific read trigger. Assign the next unused four-digit number and a kebab-case filename; add a linked row to the index.

## Context And Problem Statement

Describe the verified problem and boundaries that make the decision necessary.

## Decision Drivers

State the operational, compatibility, safety, or maintenance constraints.

## Considered Options

List real alternatives with costs; avoid invented straw alternatives.

## Decision Outcome

State the chosen option, consequences, authorities, compatibility impact, and rollout or supersession rules.

## Validation

Name implemented tests/guards and any manual checks. Distinguish locally verified checks from automatically enforced checks.

## More Information

Link governing instructions, implementation, tests, and related/superseded decisions. Identify reconstructed evidence where applicable.
